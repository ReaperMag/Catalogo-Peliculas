# CineBase - Gambito de Dama (React + Tailwind CSS)

Componente completo réplica de la ficha técnica cinematográfica de CineBase con tema oscuro, paleta oro/ambar y Space Grotesk / Inter.

## Instalación y Ejecución

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev
```

Abre tu navegador en `http://localhost:5173` o el puerto que indique la terminal.

## Tecnologías
- React 19 + TypeScript
- Tailwind CSS
- Lucide React
